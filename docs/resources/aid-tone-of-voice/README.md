# AID Tone Of Voice Resources

This folder contains source reference materials for Arena Repurpose Studio iOS output design.

These files are project resources for product, prompt, and template work. They are not part of the SwiftUI runtime target and do not introduce API, networking, backend, Keychain, App Intents, or Share Extension behavior.

## Files

- `tone_of_voice_aid_post_facebook_top_prompt_aid_e_blog.md`: AID tone of voice for Facebook posts, top prompt posts, comment sequences, and blog/article outputs.
- `Tono di Voce Aid stile Universitario #Project Work 9_1 Scienze Motorie.md`: university-style Project Work 9.1 Scienze Motorie example and tone reference.

## Usage

Use these resources when refining product requirements, structured generation requests, output templates, acceptance criteria, and future tests for AID, Prof Arena, and LevelUp content families.
