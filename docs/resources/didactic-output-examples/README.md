# Didactic Output Examples

This folder contains reference examples of real teaching materials used by Mariangela. They are product and template references for Arena Repurpose Studio iOS, not runtime app assets.

These examples should guide future structured generation requests and output templates for first-year upper secondary school, fifth-year technical/vocational subjects, and inclusive didactic material.

## Files

- `1u-diritto-la-capacita-giuridica-mappa.pdf`: first-year law material on legal capacity, with simplified explanation and map-oriented recap.
- `5w-estimo-stima-dei-frutteti.docx`: fifth-year Estimo material on orchard valuation, with definitions, guiding questions, formulas, procedures, and reminders.
- `5w-italiano-il-realismo.pdf`: fifth-year Italian literature material on Realism, Naturalism, Verismo, historical context, techniques, and comparison table.
- `5w-italiano-giovanni-verga.pdf`: fifth-year Italian literature material on Giovanni Verga, Verismo, works, narrative techniques, language, and worldview.

## Output Traits To Preserve

- Clear school level and class target.
- Direct explanatory style suitable for classroom use.
- Key definitions before complex reasoning.
- Frequent guiding questions and exam-style prompts.
- Bullet lists, recap sections, tables, maps, or schema-friendly structures.
- Concrete examples after abstract concepts.
- Visual or conceptual organization that can support BES/DSA students.
- Discipline-specific precision without unnecessary academic overload.
- For Estimo, formulas and estimation procedures must remain explicit and step-by-step.
- For Italian literature, historical context, key concepts, author profile, works, techniques, language, and likely questions must remain visible.

## Product Use

Use these examples when designing future final-output templates such as:

- simplified didactic material;
- lesson summaries;
- BES/DSA maps;
- evaluation or oral-exam preparation sheets;
- technical subject handouts;
- fifth-year project-oriented study notes;
- Markdown didactic materials with recap and map sections.

Do not add these files to the SwiftUI target or use them to introduce PDF/DOC parsing in the current MVP.
